# Sidenote

A live meeting assistant for the Claude desktop app.

Sidenote opens a small window next to your meeting. It reads the captions from
Google Meet (with speaker names) or from your computer's Live Captions, keeps a
transcript, agenda, action items and questions to ask, and lets you ask Claude
about the meeting while it happens.

## Start

Type **open Sidenote** in a Claude chat.

## Needs

- macOS: turn on Claude in System Settings > Privacy & Security > Device Control
  and Data Access (Accessibility on older macOS), so Sidenote can read captions.
- Windows: Windows 11 with Live Captions, or Google Meet in Chrome or Edge.

Python and the packages Sidenote uses are installed by Claude when you install
the extension.

## Your data

Meeting files are saved only on your computer, in Documents/Sidenote.
