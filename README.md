# Sidenote

A live meeting assistant for the Claude desktop app (Windows and Mac).

Sidenote reads the captions of your call (Google Meet, or Live Captions for any other app), keeps a running transcript, and lets you ask Claude about the meeting in a small always-on-top window, without leaving the call.

In a Claude chat, type: open Sidenote

See SIDENOTE.md for the full feature list.

## Files

- sidenote.py: the whole app (a local MCP server started by the Claude desktop app)
- requirements.txt: Python packages it needs
- SIDENOTE.md: objective and feature list

Meeting transcripts are saved on your own computer in Documents/Sidenote and are never part of this repository.
